# CodeAlpha_TaskAutomation

A Python-based Task Automation toolkit with an interactive Streamlit UI.

## 🚀 Features
- **Email Extractor**: Regex-based email extraction from text or `.txt` file uploads.
- **Web Title Scraper**: Web scraping using `requests` and `BeautifulSoup` to extract page titles.
- **File Organizer**: Automated file sorting by extension (`os` & `shutil`).
- **File Downloads**: Save extracted emails and scraping results instantly.
